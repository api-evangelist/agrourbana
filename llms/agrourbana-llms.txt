# AgroUrbana

> AgroUrbana SpA is a Chilean vertical-farming company founded in 2018 in Santiago, widely
> described as the first commercial vertical farm in Latin America. It grows leafy greens in
> climate-controlled indoor facilities using hydroponics, spectrum-programmed LED lighting,
> automation and data analytics, and sells them to Chilean retailers and direct to consumers
> under the Urban Rabbit brand.

## Important for agents

AgroUrbana publishes **no public API**. There is no developer portal, no API reference, no
OpenAPI/AsyncAPI/GraphQL contract, no SDK, no CLI, no MCP server and no A2A agent card on any
host the company operates. Every discovery path was probed on 2026-09-13 and every one missed;
the probe record is in this repository. Do not attempt to call an AgroUrbana API — none exists.
The company's technology is operated internally to run its own farms.
